# Hannah Tipperman's Personal Website 🎮

A retro pixel art-inspired personal website showcasing my work as a Senior Software Engineer.

## 🎨 Design

This site features a nostalgic early-web aesthetic with:
- **Retro pixel art styling** with neon color palette
- **Terminal/console-inspired elements** 
- **Animated glitch effects** and scan lines
- **Responsive design** that works on all devices
- **Accessibility features** including reduced motion support

## 🛠️ Tech Stack

- Pure HTML5 & CSS3 (no frameworks needed!)
- Modern CSS Grid & Flexbox
- CSS animations and custom properties
- Semantic HTML for better accessibility

## 🚀 Development

This is a static site hosted on GitHub Pages. To run locally:

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process required.

## 🎯 Features

- Single-page design with all content easily accessible
- Smooth scrolling and animations
- Print-friendly styles
- Fast loading times
- Mobile-first responsive design
